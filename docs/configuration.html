Configuration reference

Every option of mercuriod's TOML configuration file, with its default. Every option is optional.

The broker reads /etc/mercurio/config.toml, or the file given with -c. A commented file with every option is provided as mercuriod/contrib/config.toml.

Top level

OptionDefaultMeaning
include_dirDirectory whose *.toml files are merged into this one, in name order. Their tables extend this file's, their arrays ([[listeners]], [[bridges]]) are added to this file's, and their other values replace this file's.
# /etc/mercurio/config.toml
include_dir = "/etc/mercurio/conf.d"

# /etc/mercurio/conf.d/tenant1.toml adds a listener
[[listeners]]
port = 1885
mount_point = "tenant1/"

[server]

Main listener

OptionDefaultMeaning
host"127.0.0.1"Address to listen on. "0.0.0.0" for every IPv4 interface, "::" for IPv6.
port1883Port of the main MQTT listener.
bind_interfaceOnly accept connections arriving on this network interface, such as "eth0". Linux only.
websocket_portAlso serve MQTT over WebSocket on this port, with the main listener's TLS settings.
http_dirServe the files of this directory to plain HTTP requests on websocket_port.

Limits

OptionDefaultMeaning
max_connections10000Concurrent connections, across every listener. Further ones are closed right after being accepted.
max_packet_size1048576Largest packet accepted from a client, in bytes. Announced to MQTT 5 clients.
connect_timeout10Seconds a new connection has, in all, to send its PROXY header, complete the TLS and WebSocket handshakes and send CONNECT, enhanced authentication included.
max_queued_messages10000Messages that may wait for one client, any QoS, before further ones are dropped.
max_queued_qos0_messages1000Queued messages beyond which QoS 0 messages are dropped.
max_queued_bytes104857600Payload bytes that may wait for one client before further messages are dropped.
receive_maximum65535QoS 2 messages an MQTT 5 client may have awaiting PUBREL at once.
max_topic_alias10Highest topic alias MQTT 5 clients may use; 0 disables aliases.
max_keepaliveLongest keep-alive, in seconds, MQTT 5 clients may use. Clients asking for more, or for none, are told to use this one.
max_qos2Highest QoS clients may use. Subscriptions above it are granted this QoS; publishing above it closes the connection.
retain_availabletrueWith false, retained messages are refused, and so are wills that ask to be retained.

Client ids and sessions

OptionDefaultMeaning
allow_zero_length_clientidtrueAccept clients that send an empty client id and assign them one.
auto_id_prefix""Prefix of the client ids the broker assigns.
clientid_prefixes[]When not empty, only client ids starting with one of these are accepted; others are refused as not authorized.
persistent_client_expirationneverSeconds the session of an MQTT 3.x client connected without clean session outlives its connection. MQTT 5 clients choose their own expiry.
max_session_expiryunboundedMost seconds any session may outlive its connection. MQTT 5 clients asking for longer, or for no expiry, are told to use this; it also bounds persistent_client_expiration. Worth setting where clients aren't trusted, as each stored session takes memory and storage.
max_retained_messagesunboundedTopics that may hold a retained message at once, about 20 of the broker's own $SYS topics included. Retaining a message on another topic is refused with Quota Exceeded; updating or clearing a retained topic is always allowed.
max_connections_per_ipunboundedConnections one client address may hold at once; further ones are closed. Behind a proxy sending PROXY headers, the address the header gives is counted, so set proxy_from too. Unbounded by default, as carrier NAT puts many devices behind one address.

Delivery

OptionDefaultMeaning
upgrade_outgoing_qosfalseSend messages at the QoS of the subscription even when published with a lower one. Goes beyond the MQTT specification.
max_subscriptions10000Subscriptions one session may hold. Further ones are refused with Quota Exceeded; replacing one it holds is allowed.
check_retain_sourcefalseSend a retained message to new subscribers only while the client that published it may still publish to its topic.
send_topic_aliasesfalseReplace repeated topics with aliases for MQTT 5 clients that accept them. Off by default because some client libraries announce alias support they don't implement.
response_informationTopic prefix given to MQTT 5 clients that request Response Information; %c is replaced by the client id, as in "responses/%c".
sys_interval10Seconds between updates of the $SYS statistics; 0 disables them.

[server.redirect]

Sends every client to another server instead of serving it. MQTT 5 clients are told where to go; MQTT 3.x clients only learn that this server is unavailable.

OptionDefaultMeaning
server_referencerequiredWhere to go, such as "broker2.example.com:1883".
permanentfalseServer Moved when true, Use Another Server otherwise.

[server.tls]

TLS for the main listener, and for websocket_port. [listeners.tls] takes the same options. See TLS.

OptionDefaultMeaning
enabledfalseServe TLS instead of plain TCP.
cert_pathCertificate chain, PEM.
key_pathPrivate key, PEM: PKCS#1, PKCS#8 or SEC1.
ca_pathRequire clients to present a certificate signed by this CA.
crl_pathRefuse client certificates revoked in these CRLs, PEM. Needs ca_path.
identity_as_usernamefalseUse the client certificate's Common Name as the user name. Needs ca_path.
subject_as_usernamefalseUse the whole certificate subject as the user name, in RFC 2253 form. Needs ca_path.
min_version"1.2"Oldest TLS version accepted: "1.2" or "1.3".

[logging]

OptionDefaultMeaning
level"info"trace, debug, info, warn or error, or per module, as in "info,mercurio_server::session=warn".
fileAppend logs to this file instead of standard output.
syslogfalseSend logs to the local syslog daemon through /dev/log.
connection_messagestrueLog clients connecting and disconnecting.

[storage]

OptionDefaultMeaning
backend"memory""memory", lost on restart, "sqlite" or "postgres".
pathThe SQLite database file, with backend = "sqlite".
urlThe PostgreSQL database, such as "postgres://mercurio:password@localhost/mercurio", with backend = "postgres". PostgreSQL 12 or later, connected to directly, without PgBouncer. The broker creates its tables on start. Connections are encrypted when the server supports it; add ?sslmode=require to insist on it, or ?sslmode=disable to never encrypt.
ca_pathMozilla's root certificatesPEM file of the certificate authority that signed the PostgreSQL server's certificate, such as a cloud provider's bundle. The certificate and the host name are always verified.
standbyfalseWith PostgreSQL, when another broker is using the database, wait and take over once it stops, instead of exiting. See Standby brokers.

[auth]

See Authentication & access. [listeners.auth] takes the same options.

OptionDefaultMeaning
enabledfalseRequire clients to authenticate.
allow_anonymousfalseWith authentication enabled, still accept clients that send no user name.
password_fileUser names and password hashes.
acl_fileTopic access rules, in mosquitto's format.
dynamic_securityDynamic security state file; replaces password_file and acl_file. Only in [auth].

[auth.http]

OptionDefaultMeaning
user_urlEndpoint checking logins; replaces password_file.
acl_urlEndpoint checking topic access; replaces acl_file.
timeout_seconds5Longest wait for an answer; a timeout denies.
cache_seconds30How long topic answers are reused.

[[listeners]]

Each entry adds a listener. See Listeners.

OptionDefaultMeaning
host"127.0.0.1"Address to listen on.
portTCP port. Either this or path.
pathUnix domain socket. Either this or port.
protocol"mqtt""mqtt" or "websocket".
http_dirWith "websocket", serve this directory's files to plain HTTP requests.
proxy_protocolfalseConnections start with a PROXY protocol header, v1 or v2.
proxy_fromanyWith proxy_protocol, the addresses or CIDR blocks of the proxies allowed to send the header, such as ["10.0.0.0/8"]. Connections from elsewhere are closed, as their header could claim any address.
mount_pointPrefixed to every topic the listener's clients use. Must end with /.
max_connectionsConcurrent connections on this listener, on top of the broker-wide limit.
bind_interfaceOnly accept connections arriving on this interface. Linux only.
[listeners.tls]Same options as [server.tls].
[listeners.auth]Same options as [auth], except dynamic_security. Replaces [auth] for this listener.

[[bridges]]

Each entry connects to another broker. See Bridges.

OptionDefaultMeaning
namerequiredNames the bridge in logs and in its default client id.
host, portport 1883The remote broker.
addressesRemote brokers as "host:port", tried in turn; replaces host and port.
protocol_version"mqttv5""mqttv5" or "mqttv311".
client_id"mercurio-bridge-<name>"Client id on both brokers.
username, passwordCredentials for the remote broker.
notificationstruePublish the bridge's state, retained, to $SYS/broker/connection/<client id>/state.
[bridges.tls]enabled, ca_path, and cert_path with key_path for mutual TLS.

[[bridges.topics]]

OptionDefaultMeaning
patternrequiredTopic filter to forward.
direction"out""out" to the remote broker, "in" from it, or "both".
qos0QoS of the bridge's subscriptions.
local_prefix""Where pattern sits on this broker.
remote_prefix""Where pattern sits on the remote broker.
